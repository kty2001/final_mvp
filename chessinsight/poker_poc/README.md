# 포커(홀덤) 엔진 PoC

체스 MVP의 "수마다 최선 대비 손실" 구조를 포커에 적용할 수 있는지 확인하는 PoC. 엔진은 TexasSolver(GTO 솔버).

## 결론

- **가능.** 히어로의 결정마다 GTO 빈도, 행동별 EV, 실제 행동의 EV 손실을 계산함.
- TexasSolver 출력에는 **EV가 없고 전략(빈도)만 있음**. 덤프된 양측 균형 전략으로 트리를 직접 평가해 EV를 계산함(`run_poc.py`의 `Evaluator`).
- EV 계산 검증: 균형에서는 섞어 쓰는 행동들의 EV가 같아야 함. 리버 결정에서 GTO가 섞는 8개 콤보의 행동 간 EV 차이는 **팟 대비 0.15~1.04%**(해의 exploitability 0.28%)로 정상 범위.

## 실행

```powershell
# 1) https://github.com/bupticybee/TexasSolver/releases 에서 TexasSolver-v0.2.0-Windows.zip 을 받아 engine/ 에 압축 해제
#    (라이선스상 바이너리 재배포 금지라 저장소에 포함하지 않음)
# 2) 실행 (Python 표준 라이브러리만 사용)
python run_poc.py              # spot.json 해석 + 결정별 리포트
python run_poc.py --validate   # + EV 계산 검증
python run_poc.py --resolve    # 캐시 무시하고 다시 해 풀이
```

해 풀이 결과는 `out/solution.json`에 캐시되며, `spot.json`이 바뀌면 자동으로 다시 품.

## 샘플 결과 (`spot.json`)

100bb, BTN 오픈 / BB 콜, 플랍 Kh9d4c(체크-베팅-콜) 이후 턴 7s, 리버 2h. 히어로 BB Tc9h.

| 결정 | 상황 | 실제 | GTO | EV 손실 | 분류 |
|---|---|---|---|---|---|
| 1 | 턴 첫 행동 | 체크 | 체크 100% | 0 | 양호 |
| 2 | 턴 7bb 베팅에 대응 | 콜 | 콜 100% | 0 | 양호 |
| 3 | 리버 첫 행동 | 체크 | 체크 100% | 0 | 양호 |
| 4 | 리버 17bb 베팅에 대응 | 콜 | 폴드 100% | 1.34bb (팟 대비 3.4%) | 부정확 |

- 해 풀이: 15~19초(8스레드), exploitability 0.28%, 결과 JSON 약 50MB
- EV 계산: 약 21초(순수 Python)
- 분류 기준(임시): EV 손실이 팟 대비 2% 이상 부정확, 5% 이상 실수, 10% 이상 블런더

## 확인한 엔진 동작 (문서에 없는 부분)

| 항목 | 확인 결과 |
|---|---|
| 출력 JSON | `node_type`(action_node·chance_node), `player`, `actions`, `strategy`(콤보별 행동 빈도), `childrens`, `dealcards`. **EV 없음** |
| 플레이어 번호 | 루트(먼저 행동하는 OOP) = 1, IP = 0 |
| `set_effective_stack` | 팟을 뺀 남은 스택 |
| `BET x` / `RAISE x` | 그 스트리트 누적 금액(raise-to). 금액은 정수로 반올림됨(75% × 9 = 6.75 → 7) |
| 올인 | 별도 라벨 없이 `BET 95`처럼 표시 |
| 종료 노드 | 폴드·쇼다운은 자식 노드 없음. 자식이 모두 종료면 `childrens` 키 자체가 없음 |
| 올인 후 딜 | 이후 결정이 없으면 `dealcards`가 덤프되지 않음 → 남은 카드를 직접 깔아 평균 |
| 보드와 겹치는 콤보 | 불가능한 핸드인데도 균등 빈도(예: 33/33/33)로 채워져 있음 → 분석에서 제외 필요 |

## 한계

- **턴부터만 해석.** 플랍부터 풀면 리버까지 덤프해야 해서 결과 JSON이 턴 해석의 수십 배(턴 카드 수만큼)로 커질 것으로 예상(미측정). 플랍·프리플랍 결정 분석에는 행동별 EV를 직접 내주는 엔진(postflop-solver 등, Rust 필요)이나 스트리트별 분할 해석이 필요.
- **레인지 단순화.** 턴 시점 레인지로 프리플랍 레인지(TexasSolver 동봉 6max BTN/BB)를 그대로 사용. 플랍 행동에 따른 레인지 축소는 미반영.
- 베팅 사이즈는 스트리트당 1개 + 올인으로 제한. 실제 핸드의 사이즈가 다르면 가장 가까운 사이즈로 대응.
- 핸드 히스토리 파서 없음(`spot.json` 직접 작성).
- TexasSolver 마지막 릴리스는 v0.2.0(2021-11).
