## 1. 서비스 정의

### 1-1. 한 줄 정의

> 교사가 곁에 없는 가정에서, 아이가 교과 개념을 **자기 말로 설명·예측·적용**하게 하고, 그 응답을 분석해 **어떤 오개념이 있는지 → 무엇을 보충할지 → 다시 풀었을 때 무엇이 달라졌는지**까지 이어 주는 학습 서비스.
> v2부터는 암기가 필요한 내용(사회 용어, 영어 어휘 등)을 **인출 연습·간격 반복으로 오래 기억**하게 하고, 이해·기억·메타인지·학습 습관을 부모가 한 화면에서 보는 **학습 기반 지표**를 함께 제공함

### 1-2. 핵심 학습 흐름

```
[이해 루프 — 핵심]
교육과정 연계 개념 수업 → 서술형 추론 응답(설명·예측·적용 + 확신도) → AI 피드백 + 부모 검토
   → 오개념 기반 보충 학습 → 변형 문항 재도전 → 응답 변화 비교 → 실생활 적용 과제

[기억 루프 — v2 추가]
암기 카드 인출(보고 떠올려 쓰기 + 확신도) → 채점(정답·혼동·오답) → 혼동 쌍이면 대비 카드
   → 간격 복습(1·3·7일) → 외운 사실로 설명하기(이해 루프로 연결)

[학습 기반 지표 — v2 추가]
두 루프의 응답·복습·세션 기록 → 이해·기억·메타인지·학습 습관·탐구 발상(관찰) → 부모 화면
```

| 교과 성격 | 적용 루프 | 예 |
|---|---|---|
| 개념 이해 중심 | 이해 루프 | 초등 과학(물의 상태 변화, 열의 이동) |
| 암기 + 원인·결과 설명 혼합 | 기억 루프 → 이해 루프 연결 | 초등 사회(촌락과 도시: 용어 암기 후 "왜 도시에 사람이 모일까" 설명) |
| 암기 중심 | 기억 루프 단독 | 영어 어휘, 한국사 연표 |

| 단계 | 내용 | 산출물 |
|---|---|---|
| 개념 수업 | 성취기준 1개 단위의 짧은 개념 학습(영상·카드) | 학습 완료 기록 |
| 추론 응답 | 설명(왜 그런가) · 예측(조건이 바뀌면) · 적용(새 상황) 3문항 | 서술형 응답(유아는 구술·그림) |
| 피드백 | 개념 정확성·근거 연결·추론 단계 누락을 항목별로 진단, 오개념 태그 부여 | 피드백 카드, 오개념 태그 |
| 부모 검토 | AI 초안 확인 + 아이에게 던질 질문 제시 (정답 해설 아님) | 부모 코칭 질문 |
| 보충 학습 | 오개념 태그별 보충 카드(반례·실험·그림) | 보충 학습 기록 |
| 재도전 | 같은 개념, 다른 상황의 변형 문항 | 재응답 |
| 변화 비교 | 1차·2차 응답을 나란히 놓고 달라진 근거를 표시 | 성장 기록 |
| 적용 | 집에서 해 볼 관찰·실험 과제 | 활동 기록 |
| 암기 인출 (v2) | 카드 앞면을 보고 답을 직접 써서 떠올리기(보기 고르기 아님), 확신도 표시 | 인출 기록 |
| 혼동 진단 (v2) | 비슷한 용어와 바꿔 쓴 오류를 혼동 태그로 분류 → 두 용어를 나란히 놓은 대비 카드 | 혼동 태그 |
| 간격 복습 (v2) | 맞히면 1→3→7일 뒤 다시, 틀리면 다음 날 다시 | 기억 유지 기록 |
| 연결 설명 (v2) | 외운 용어를 써서 원인·결과를 설명하는 문항(이해 루프로 진단) | 서술형 응답 |

### 1-3. 흐름 예시 (초4 과학 · 물의 상태 변화)

| 단계 | 예시 |
|---|---|
| 설명 | "차가운 컵 겉면에 물방울이 맺히는 이유를 설명해 보세요." |
| 아이 응답 | "컵 안의 물이 컵을 뚫고 밖으로 스며 나와서요." |
| 진단 | 오개념 태그: `스며 나옴(공기 중 수증기 미인식)` · 근거 연결 없음 |
| 부모 코칭 질문 | "컵에 주스를 넣으면 겉에 맺힌 물방울도 주스 맛일까?" |
| 보충 | 반례 카드: 빈 컵을 냉동실에 넣었다 꺼내도 물방울이 맺힘 |
| 재도전(예측) | "얼음물 대신 미지근한 물을 넣으면 물방울은 어떻게 될까요? 이유는?" |

### 2-1. 문제

| 문제 | 내용 | 상태 |
|---|---|---|
| 서술형·논술형 평가 확대 | 교육청별 AI 서·논술형 평가 시스템 도입·확대(경기 하이러닝 2025년 6월 개통, 부산 2027년까지 단계 확대) | 확인됨 |
| 가정 학습은 객관식 진단 중심 | 홈러닝·EBS 단추 플러스는 진단→개념→심화 경로 제공, 서술형 추론 피드백은 문해력 일부에서만 시작 | 확인됨(조사 2-C) |
| 가정에는 검토자가 없음 | 공교육·민간 서술형 피드백은 모두 교사 검토를 전제로 설계됨. 부모는 무엇을 봐야 할지 모름 | `[가설]` 인터뷰로 검증 |
| 답은 맞혀도 설명은 못 함 | 글에 명시된 기능은 설명을 많이 한 학생과 적게 한 학생이 비슷하게 답했지만, **글에 암시만 된 기능을 추론하는 문항에서는 설명을 많이 한 학생이 크게 앞섬**(Chi 1994, 2-3). 일상 현상을 과학 용어로 설명한 학생 7.9%(응결 연구, 원문 확인 필요) | 부분 확인. 국내 "정답 중 근거 오류 비율"은 자체 측정(6-3 H11) |
| 부모의 지도 부담 | 18세 미만 자녀가 있는 가구의 맞벌이 비율 58.5%(막내 7~12세 59.8%, 2024년 10월) [R5]. 서술형 답안을 봐 줄 시간·자신감 부족 | 맞벌이는 확인. 검토 어려움 비율은 국내 조사 없음 → 자체 설문 |

### 2-3. 논술적 사고력이 필요한 근거 (연구)

**① 사회적 수요**

| 근거 | 내용 |
|---|---|
| WEF 미래 일자리 보고서 2025 | 분석적 사고가 고용주가 꼽은 1위 핵심 역량, 기업 10곳 중 7곳이 필수로 봄(직전 두 판과 동일). 1,000개 이상 기업·55개국 조사. 'AI·빅데이터'를 핵심 역량으로 꼽은 기업은 절반 미만 [R15] |

**② AI 시대에 더 필요해진 이유 — 답을 주는 AI는 학습을 해칠 수 있음**

| 연구 | 설계 | 결과 |
|---|---|---|
| Bastani 외(PNAS, 2025) | 고등학생 약 1,000명 현장 실험. 일반 ChatGPT형(GPT Base) vs 학습 보호 프롬프트형(GPT Tutor) vs 미사용 | 연습 중 점수는 각각 48%·127% 상승. 그러나 **AI 없이 본 시험에서 GPT Base 집단은 미사용 집단보다 17% 낮음**, GPT Tutor 집단은 미사용과 차이 없음. GPT Base 학생은 배운 만큼 배웠다고 착각 [R16] |
| Lee 외(CHI 2025, Microsoft Research) | 지식노동자 319명, 실제 사용 사례 936건 설문 | AI를 더 신뢰할수록 비판적 사고를 덜 함, 자기 확신이 높을수록 더 함 [R17] |
| Kosmyna 외(MIT 미디어랩, 2025, 논문 심사 전) | 54명 에세이 작성: LLM / 검색 / 도구 없음 | 외부 도움이 많을수록 뇌 연결성 감소. LLM 집단은 자기 에세이를 인용하지 못하는 비율이 높았다는 보도(수치 원문 확인 필요). 표본이 작음 [R18] |

→ **설계 함의**: 답을 먼저 주지 않고 학생이 먼저 설명하게 한 뒤 피드백(6-2·6-3), 해설은 설명 이후 공개. Bastani 연구의 GPT Tutor(학습 보호형)가 미사용 수준을 유지했다는 점이 이 설계의 직접 근거

**③ 설명·글쓰기·논증을 한 학생 vs 하지 않은 학생 (비교 실험)**

| 연구 | 설계 | 결과 |
|---|---|---|
| Chi 외(1994, Cognitive Science) | 중2 순환계 학습. 문장마다 스스로 설명하도록 유도한 집단(14명) vs 같은 글을 두 번 읽은 통제 집단(10명) | 유도 집단의 사전→사후 향상이 더 큼. **설명을 많이 한 학생은 모두 올바른 순환계 모형에 도달**, 통제 집단·설명을 적게 한 학생은 다수가 도달 못 함. 글에 암시만 된 기능 추론에서 차이가 큼 [R19]. 표본이 작음 |
| Bisra 외(2018) 메타분석 | 자기설명 유도 64개 연구 | g = 0.55. 교사 설명이나 글로 된 해설을 주는 것보다 효과적이라는 요약 있음 [R7] |
| Graham 외(2020) 메타분석 | 1~12학년, 교과 내용을 글로 쓰게 한 56개 실험(사전검사 있는 실험·준실험만) | 효과크기 0.30. 과학·사회·수학, 초·중·고에서 비슷하게 효과 [R9] |
| Abrami 외(2015) 메타분석 | 비판적 사고 교육 341개 효과크기 | 평균 0.30. **대화 + 실제 문제 적용 + 멘토링을 결합하면 약 0.57** [R20] |
| Hand 외(2018) 군집 무작위 배정 실험 | 초등 과학, 논증 기반 탐구(과학 글쓰기 발견법, SWH) vs 일반 수업 | 비판적 사고 점수 유의 향상(효과크기 0.167). **취약계층·특수교육 대상·다문화 학생에서 향상 폭이 가장 큼**. 과학 내용 점수는 유의 차이 없음 [R21] |
| Chase 외(2009) 가르칠 수 있는 에이전트 | 중2 생물: 자기 AI 학생을 가르친다고 믿은 집단 vs 스스로 배운다고 믿은 집단 | 가르치는 집단이 학습 활동에 시간을 더 쓰고 더 많이 배움. **하위 성취 학생에서 효과가 가장 큼**(프로테제 효과) [R22] |
| Fiorella·Mayer(2013) | 가르칠 준비 vs 실제로 설명하기, 4개 실험 | 가르칠 준비는 단기 효과, **실제로 설명하기는 더 깊은 생성적 처리를 일으켜 장기 학습에 유리** [R22] |
| McDaniel 외(2007) | 대학 수업 주간 퀴즈: 단답형 vs 객관식 vs 퀴즈 없음 | 단답형 퀴즈가 객관식보다 효과가 더 견고. 단, 후속 교실 연구에서는 차이가 일관되지 않음 [R22] |

**④ 해석과 한계**

- 효과크기는 대부분 작은~중간 수준(0.17~0.57). "성적을 크게 올린다"가 아니라 **"이해의 깊이·전이·비판적 사고를 꾸준히 높인다"**로 주장
- Hand 2018처럼 비판적 사고는 오르지만 내용 점수는 차이가 없는 경우가 있음 → 성과 지표를 정답률만이 아니라 설명 정확도·오개념 해소율로 둔 이유(5-7 ①)
- 하위 성취·취약계층에서 효과가 크다는 결과(Chase 2009, Hand 2018)는 공공 바우처 채널(8-5)의 근거로 활용 가능
- 해외 연구 중심이므로 국내 효과는 파일럿으로 확인 `[측정 예정]`

|---|---|

| 항목 | 내용 |
|---|---|
| 정체 | 스탠퍼드 교육대학원 학습설계·기술(LDT) 과정의 학생 프로젝트(2023). 상용 서비스·출판 연구 아님, **학습 효과 데이터 없음** [R23] |
| 대상·방식 | 중·고등학생이 AI 챗봇에게 개념을 가르치면, AI가 지식 공백과 오개념을 찾아내고 후속 질문으로 이해 깊이를 확인. 생성형 AI로 만든 '가르칠 수 있는 에이전트' [R23] |
| 이론적 배경 | **가르치며 배우기(learning by teaching)**. 스탠퍼드 Schwartz 연구실의 '가르칠 수 있는 에이전트(Betty's Brain)' 연구 계보. 자기 AI 학생을 가르친다고 믿은 학생이 더 노력하고 더 많이 배운 프로테제 효과(Chase 외 2009) [R22] |
| 우리와 같은 이유 | 둘 다 "스스로 설명하게 하면 이해가 깊어지고 오개념이 드러난다"는 같은 연구 기반(자기설명 Chi 1994·Bisra 2018, 가르치며 배우기 Chase 2009·Fiorella·Mayer 2013, 2-3)에서 출발 |
| 우리와 다른 점 | 교육과정·성취기준 연결 없음, 오개념 태그 체계와 보충→재도전→변화 비교 루프 없음, 검토자(부모·지도자) 없음, 한국어·국내 평가(서·논술형, 수능) 대응 없음 |
| 함의 | 설명형 구조 자체는 연구로 뒷받침되지만 **독점할 수 있는 아이디어가 아님**. 차별은 교육과정 연계 오개념 태그 데이터, 재도전 루프, 교사 없는 곳의 검토자 설계에서 나와야 함(5-7). 가르치는 모드는 확장 기능 후보(2-3 ⑤) |

**F 유형 상세 비교 (천재 AIDT 기준, 공개 보도)**

| 항목 | 천재 AIDT | 우리 기획안 |
|---|---|---|
| 사용 장소·주체 | 학교 수업, 교사 대시보드 | 가정, 부모·학생 |
| 구매자 | 학교(학교장·학교운영위원회 심의) | 가정(B2C) |
| 학생 응답 형식 | 문제풀이·정오답 중심. 교육부 기준으로 생성형 AI를 빼고 규칙 기반 챗봇만 둔 발행사 사례 있음 [A1] | 서술형·구술 설명을 LLM으로 진단 |
| 진단 단위 | 학습 수준(느린/빠른 학습자)·이해도, AI 총평 초안을 교사가 수정 [A1] | 오개념 태그 |

- **경쟁 구도상 위험**: 천재교과서는 학교(AIDT·교육자료), 가정(밀크T), 학원(해법독서논술) 세 경로를 모두 보유. 학습 기록이 연결되면 가정용 교과 사고력 영역을 바로 채울 수 있음 (5-6)
- 천재 AIDT의 실제 서술형 진단 기능 여부는 T셀파·체험 계정으로 확인 필요

## 5. 차별점 — 가져갈 것

조사 결과 "서술형 AI 피드백" 자체는 이미 범용 기능임. 차별점은 **피드백 이후의 흐름, 피드백을 받는 사람, 응답의 형식**에서 가져감.

### 5-1. [핵심] 서술형 응답 → 오개념 진단 → 보충 → 재도전 → 변화 비교 루프

| 항목 | 내용 |
|---|---|
| 무엇 | 서술형 응답에서 오개념을 태그로 뽑고, 태그별 보충 카드와 변형 문항으로 바로 연결. 1차·2차 응답을 나란히 비교해 달라진 근거를 표시 |
| 왜 차별점인가 | 경쟁사 보충 경로는 객관식 정오답 기반(EBS 단추), 서술형 서비스는 피드백에서 끝나거나 재작성 기능 준비 단계(자작자작). "설명이 틀린 이유"로 보충 경로를 정하는 곳은 확인 안 됨 |
| 고객 가치 | 부모·아이 모두 "점수"가 아니라 "생각이 어떻게 바뀌었는지"를 봄 |
| 방어 요소 | 성취기준별 **오개념 태그 체계와 태그→보충 매핑 데이터**가 사용량과 함께 쌓임. 기능은 따라 할 수 있어도 매핑 품질은 축적이 필요 |
| 검증 지표 | 재도전 후 오개념 해소율, 1차→2차 개념 정확성 점수 변화 `[측정 예정]` |

### 5-2. [핵심] 교사 대신 부모를 검토자로 세우는 "부모 코칭" 설계

| 항목 | 내용 |
|---|---|
| 무엇 | AI 피드백을 아이에게 바로 주지 않고, 부모 화면에 ① 한 줄 진단 ② 아이에게 던질 질문 2개 ③ 정답을 바로 말하지 말아야 할 이유를 제시. 부모가 확인하면 아이 화면에 피드백 공개 |
| 왜 차별점인가 | 공교육·민간 서술형 서비스는 모두 "교사 검토"를 전제로 함. 홈러닝은 부모에게 진도·점수 리포트만 줌. 부모를 **검토·대화 주체**로 설계한 곳은 확인 안 됨 |
| 고객 가치 | 전문 지식 없이 10분 안에 아이와 개념 대화 가능, 사교육 첨삭 대체 |
| 방어 요소 | 부모 행동(질문 사용·대화 후 재응답 개선) 데이터로 질문 품질 개선 |
| 검증 지표 | 부모 검토 소요 시간, 코칭 질문 사용률, 질문 사용 시 재도전 개선 폭 `[측정 예정]` |

### 5-3. [확장] 유아 구술·그림 추론 활동

| 항목 | 내용 |
|---|---|
| 무엇 | 5~7세가 말(음성 인식)과 그림 선택·그리기로 "왜 그럴까"에 답함. 누리과정 자연탐구 영역 연계 `[출처 확인 필요]` |

### 5-7. AIDT 대비 추가 차별점

진단→추천, 대시보드, 교육과정 연계, AI+사람 검토는 AIDT 기본 기능이므로 차별점으로 주장하지 않음. 아래 다섯 가지를 가져감.

1. **설명 정확도를 대표 지표로**
   - "정답은 맞혔는데 설명은 틀림"을 잡아냄
   - 정오답 기반 진단으로는 구조상 잡을 수 없음 (6-3 근거 설명 모드와 같은 논리)

2. **교사가 없는 곳 전제**
   - AIDT: 교사 대시보드와 교사 검토가 전제
   - 우리: 초등은 부모, 중·고등은 학생 본인, 그 외 공부방 지도자가 검토자

3. **발행사 무관, 학년을 넘는 오개념 추적**
   - 어느 교과서를 쓰든 초4 → 중1 → 고1로 같은 오개념을 따라감
   - 발행사 교과서 단위로 끊기는 AIDT와 구조적으로 다름

4. **학교 도구의 보완재**
   - "학교에서 배운 단원을 집에서 자기 말로 다지는 도구"
   - 데이터 연동 없이 성취기준만 맞춤 (개인정보·학습지원 SW 기준 때문, 9-2 ⑦)

5. **선점 후 발행사를 고객으로 전환**
   - AIDT 사회·과학 도입(2027 예정) 전에 과학 오개념 데이터와 해소율 효과를 입증
   - 이후 발행사에 서술형 진단 엔진 공급(B2B2C, 10-3 1순위)

### 5-8. [v2 확장] 암기 모드 — 혼동 쌍 진단과 "외운 사실 → 설명" 연결

| 항목 | 내용 |
|---|---|
| 무엇 | 사회 용어·영어 어휘처럼 외워야 하는 내용을 ① 보고 떠올려 직접 쓰기(인출) ② 1·3·7일 간격 복습 ③ 비슷한 용어와 바꿔 쓴 오류를 **혼동 태그**로 분류해 두 용어를 나란히 놓은 대비 카드 제공 ④ 외운 용어로 원인·결과를 설명하는 문항(이해 루프)으로 연결 |
| 근거 | 학습 기법 10가지를 평가한 Dunlosky 외(2013)에서 **연습 시험(인출)·분산 연습만 '높은 효용'** [V1]. 242개 연구·1,619개 효과를 묶은 메타분석에서도 두 기법이 가장 효과적 [V2]. 단, 대부분 사실 회상 결과라 깊은 이해·전이에는 그대로 적용하기 어렵다는 한계가 명시됨 → **그래서 연결 설명 문항이 필요함** |
| 왜 차별점인가 | 간격 반복·오답노트는 H 유형 앱의 기본 기능. "왜 틀렸는지"를 혼동 쌍으로 분류하고, 외운 사실을 설명으로 이어 오개념까지 진단하는 흐름은 확인 안 됨 |
| 재사용 자산 | 오개념 태그 → 보충 → 재도전 구조를 그대로 씀(혼동 태그 → 대비 카드 → 재인출). 채점은 규칙 기반이라 AI 호출 없음(7-1) |
| 범위 | 사회(암기 + 인과 설명 혼합, 1순위), 영어 어휘(암기 단독, 2순위). 국어 문학·한국사 연표는 저작권·경쟁 상황 확인 후 |
| 검증 지표 | 7일 뒤 재인출 정답률, 혼동 태그 해소율, 암기 후 연결 설명 문항의 개념 정확성 `[측정 예정]` |

### 5-9. [v2 확장] 학습 기반 지표 — 측정 가능한 것만, 점수 대신 변화

부모 화면에서 아이의 공부 기반을 다섯 가지로 보여 줌. **행동 기록으로 측정할 수 있는 것만 지표로 삼고**, 근거가 약하거나 아이에게 부담이 되는 것은 관찰 기록으로 낮추거나 제외함.

| 지표 | 요청과의 관계 | 측정 데이터 | 표시 | 근거·주의 |
|---|---|---|---|---|
| 이해 (설명 정확도) | 기존 핵심 | 1차·2차 서술형 응답의 개념 정확성, 오개념 해소 | 1차 → 2차 변화 | 5-1 |
| 기억 (유지율) | "암기" 요청 | 간격 복습 정답률, 혼동 태그 해소 | 회차별 유지율 추세 | 인출·분산 연습 [V1][V2] |
| 메타인지 (확신도 보정) | 추가 | 응답마다 확신도(확실·반반·모름)와 실제 결과 비교 → 과신(확실한데 틀림)·과소(모름인데 맞음) 비율 | 일치율 + 과신 사례 | 메타인지·자기조절 지도 평균 +7개월 진전(EEF, 근거 강도 높음). 단 학생이 스스로 책임지는 방식이라 실현이 어렵다는 단서 [V8] |
| 학습 습관 | "집중력" 요청을 바꿈 | 세션 완료 여부, 주간 학습 일수, 문항당 소요 시간 | 주간 규칙성·완료율 | "집중력"은 의학적 함의(ADHD 등)가 있어 쓰지 않음. 카메라 미사용(5-5) |
| 탐구 발상 (관찰) | "창의성" 요청을 바꿈 | 예측 문항에서 여러 가능성·조건을 스스로 제시한 횟수("만약", "아니면" 등) | **점수 없이 사례 문장만** | 창의성 검사의 국내 타당도 한계 [V9]. 2022 개정 사회과도 창의적 사고력을 교과 역량으로 둠 [V12] |

| 원칙 | 내용 |
|---|---|
| 또래 비교 없음 | 국내 규준이 없으므로 백분위·등수 표시 안 함. 자기 자신의 이전 기록과만 비교 |
| 아이 화면 점수 없음 | 지표는 부모 화면에만. 아이에게는 "지난주보다 오래 기억했어" 같은 변화 문장만(9-1) |
| 데이터 부족 표시 | 기록이 일정 수 미만이면 지표를 계산하지 않고 "데이터 부족"으로 표시 |
| 효과 광고 금지 | "집중력·창의력·IQ 향상" 같은 문구 사용 안 함(9-2 ⑥) |
| 차별점 주장 범위 | 학습 습관 리포트는 홈러닝 기본 기능(I 유형). 차별점으로 주장하는 것은 **확신도 보정**과 **이해·기억을 같은 화면에서 잇는 것**뿐 |

### 6-3. [확장] 수능·모의고사 근거 설명 모드

> 2026-10-21 웹 검색 기준. 출처는 문서 끝 "수능·모의고사 출처(6-3)" [S1]~[S8] 참조.

**개념**

객관식 수능·모의고사 문항을 풀 때 **답과 함께 "왜 그 답인지"를 짧게 설명**하게 하고, 설명을 진단해 객관식 채점으로는 드러나지 않는 오개념을 찾아냄. 핵심 엔진(설명 → 오개념 태그 → 보충 → 재도전)을 객관식 시험에 그대로 적용하는 기능임.

| 응답 유형 | 객관식 채점 | 근거 설명 진단 | 조치 |
|---|---|---|---|
| 정답 + 올바른 근거 | 정답 | 확실한 이해 | 다음 단원 |
| **정답 + 틀리거나 빈약한 근거** | 정답 (문제없음으로 처리됨) | **숨은 오개념**(잘못된 근거로 맞힘, 찍어서 맞힘) | 보충 → 변형 문항 재도전 |
| 오답 + 근거 | 오답 | 어떤 오개념이 매력적 오답 선지로 이끌었는지 특정 | 오개념 태그 → 보충 → 재도전 |
| 오답 + 근거 없음 | 오답 | 개념 부재 | 개념 수업으로 회귀 |

**왜 필요한가**

| 근거 | 내용 |
|---|---|
| 학습 효과 | 자기설명(self-explanation) 유도 메타분석: 64개 연구 69개 효과크기, 평균 효과크기 g = 0.55(중간 크기). 교사 설명이나 글로 된 해설을 주는 것보다 효과적이라는 요약도 있음 [S1] |
| 2028학년도 수능 개편 | 사회·과학탐구 선택과목 폐지, **모든 수험생이 고1 과목인 통합사회·통합과학에 응시**. 과목당 25문항·40분으로 확대, 여러 영역을 결합한 융합형 문항 [S2][S3] |
| 시장 | 2027학년도 수능 응시 예정자 554,174명, N수생은 전년 대비 13,784명 증가(입시기관 분석, 공식 통계 아님) [S4] |
| 기존 서비스의 공백 | 기출탭탭(비상교육): AI 정오답 분석·취약 유형 추천·오답노트 [S5]. HAI 수능 한국사: "확신했는데 틀린 문제·몰랐는데 맞힌 문제" 자기 표시 오답노트 [S5]. 메가스터디: 채점·등급컷·해설강의 [S5]. 콴다: 풀이 제공. **학생이 쓴 근거를 진단하는 서비스는 확인 안 됨** |


  - H10. 수험생이 일부 문항에 근거를 입력하는 부담을 감수함 → 입력률·완료율
  - H11. 정답 문항 중 근거가 틀린 '숨은 오개념' 비율이 의미 있게 존재함 → 정답 중 근거 오류 비율
  - H12. 숨은 오개념 보충 후 다음 모의고사 해당 단원 정답률이 오름 → 단원별 정답률 변화
  - H13. 평가원·교육청 기출 이용 허락을 받을 수 있음 → 기관 문의 결과
- 비용: 문항당 AI 호출 1회로 학습 1회 진단과 같은 수준(8-4 기준 약 20원/회)

### 6-4. [v2] 학습 기반 지표 정의 `[가설]`

| 지표 | 산식 | 최소 데이터 | 표시 |
|---|---|---|---|
| 이해 | 재도전을 마친 단원에서 (2차 개념 정확성 '충족' 문항 수 ÷ 문항 수)와 1차 값 비교 | 재도전 완료 1개 단원 | 1차 → 2차 막대, 해소된 오개념 수 |
| 기억 | 간격 복습(2회차 이후) 인출 중 정답 비율. 혼동 태그는 발생 후 같은 카드를 맞히면 해소 | 복습 인출 5회 | 유지율 막대, 혼동 해소 목록 |
| 메타인지 | (확실+정답, 모름+오답, 반반) 을 일치로 보고 일치 비율. 과신 = 확실인데 오답·오개념, 과소 = 모름인데 정답 | 확신도 응답 6개 | 일치율 막대, 과신 사례 1~2개 문장 |

- **유리한 점**: 서·논술형 평가 확대로 수요 촉매가 있고, 사교육 참여 가정의 1인당 지출은 늘고 있으며, 가정용 서술형 추론 학습은 비어 있음
- **불리한 점**: 학령인구 감소, 태블릿 홈러닝 시장 역성장, 무료 공공 서비스
- **결론 `[가설]`**: 단독 B2C로 대형 사업을 만들기보다는, **B2C로 효과(오개념 해소율)를 입증한 뒤 B2B2C 엔진 공급으로 확장**하는 구조가 현실적임

## 10. 확장 방향

> 2026-10-21 웹 검색 기준. 출처는 문서 끝 "확장 방향 출처(10장)" [E1]~[E16] 참조.

### 10-1. 확장 판단 기준

확장은 **이미 쌓은 자산이 그대로 재사용되는 방향**부터 진행함.

| 핵심 자산 | 내용 | 재사용되는 방향 |
|---|---|---|
| 오개념 진단 엔진 | 설명·예측·적용 응답 → 오개념 태그 → 보충 → 재도전 → 변화 비교 | 같은 교과의 상위 학년, 다른 업체 서비스(엔진 공급) |
| 오개념 태그 데이터 | 성취기준·개념별 태그와 태그→보충 매핑 | 같은 개념이 다시 나오는 학년(초등 상태 변화 → 중등 입자 모형 → 대학 일반화학) |
| 검토자 코칭 설계 | 교사가 없는 곳에서 비전문가 검토자가 피드백을 확인하고 질문하게 하는 구조 | 부모 → 튜터·조교·공부방 지도자 |

| 평가 항목 | 질문 |
|---|---|
| 수요 | 서술형으로 개념을 설명해야 하는 평가·상황이 늘고 있는가 |
| 경쟁 | 같은 흐름(오개념 진단→재도전)을 이미 제공하는 곳이 있는가 |
| 자산 적합도 | 오개념 태그·코칭 설계를 그대로 쓸 수 있는가 |
| 진입 비용 | 콘텐츠 제작·판매 사이클·현지화 비용이 감당 가능한가 |

## 11. v2 확장 검토: 암기 교과 포함·학습 기반 지표

> 2026-10-21 웹 검색 기준. 출처는 문서 끝 "v2 확장 검토 출처" [V1]~[V12] 참조. 10-1 확장 판단 기준(수요·경쟁·자산 적합도·진입 비용)으로 평가함.

### 11-1. 암기 비중이 큰 교과(영어·사회 등)를 포함한 전체 교육 플랫폼

| 평가 항목 | 판단 |
|---|---|
| 수요 | 있음. 사회 용어·한국사 연표·영어 어휘는 학교 시험에서 여전히 암기 비중이 큼. 2022 개정 사회과는 창의적·비판적 사고력을 역량으로 두지만 [V12], 그 바탕이 되는 개념 용어 암기는 필요. 교과별 서술형·암기 비중의 공식 수치는 확인 안 됨 `[출처 확인 필요]` |
| 경쟁 | 매우 치열. 전과목은 홈러닝 3사(월 8~15만 원대, 8-3)·EBS(무료), 암기는 클래스카드·오토보카 등 무료·저가 앱(4-1 H 유형). 간격 반복·오답노트는 기본 기능 |
| 자산 적합도 | 방식에 따라 다름. **문제은행형 전과목 플랫폼**은 오개념 태그·코칭 자산이 거의 쓰이지 않음. **혼동 쌍 진단 + 설명 연결**은 태그→보충→재도전 구조를 그대로 재사용 |
| 진입 비용 | 문제은행형은 교과·학년별 문항 제작이 고정비를 크게 늘림(8-4). 암기 카드는 문항보다 제작이 가볍고 채점이 규칙 기반이라 AI 비용 없음 |
| 학습과학 근거 | 인출 연습·분산 연습이 10개 기법 중 가장 높은 효용 [V1][V2]. 단, 효과가 사실 회상에 집중되어 깊은 이해까지 보장하지 않음 → 이해 루프와 묶어야 함 |

**결론**: "완전한 교육 플랫폼"(전과목 문제은행)은 **비추천**. 대신 **암기 모드를 엔진 확장으로 채택**하고, 외운 사실을 설명 문항으로 연결하는 구조로 "암기 교과도 다루되 설명하게 하는 학습"이라는 정체성을 유지함. 적용 순서는 사회(혼합형, MVP 1단원) → 영어 어휘(암기 단독, 2단계 추가 옵션).

### 11-2. 창의성·암기·집중력 등 논리 외 지표

| 요청 지표 | 측정 가능성 | 학습 기반 효과 근거 | 경쟁 | 판단 |
|---|---|---|---|---|
| 암기(기억) | 높음: 간격 복습 정답 기록으로 바로 측정 | 강함: 인출·분산 연습 [V1][V2] | 오답 복습 기능은 흔함 | **채택**: 기억 유지율 |

**결론**: "전체 능력을 올려 주는 서비스"라는 주장은 근거가 없고 표시광고 위험이 큼(9-2 ⑥). 대신 **"공부를 잘하는 기반을 보여 주고, 근거 있는 방법(설명·인출·확신도 점검)으로 키우는 서비스"**로 범위를 좁혀 채택. 지표 리포트 자체는 홈러닝 기본 기능이므로 차별점은 확신도 보정과 이해·기억의 연결에 둠(5-9).
